# Pipecorn — GitHub

Code source : **https://github.com/cacdesign/pipecorn**

## Clone

```bash
git clone https://github.com/cacdesign/pipecorn.git
cd pipecorn
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Repo

## Workflow

- `main` = source de vérité (déploiement automatique quand connecté à Vercel)
- Pousser sur une branche puis ouvrir une PR pour toute modif substantielle
- Format de branche : `<type>/<kebab-case>` — `feat/…`, `fix/…`, `content/…`, `design/…`, `docs/…`
- Format de commit : `<type>: <message à l'impératif, en minuscules>`
